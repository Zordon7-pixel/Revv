# REVV Logo Assets

Permanent REVV brand assets live in `frontend/public`:

- `revv-logo-wordmark.png` — full horizontal wordmark for marketing, docs, and brand use.
- `revv-logo.jpg` — full horizontal wordmark fallback for older app references.
- `revv-app-icon-1024.png` — square app-store/source icon.
- `icon-512.png` — PWA/apple-touch icon.
- `icon-192.png` — PWA icon.
- `favicon.png` — browser favicon.

The square app icon uses the REVV `R` gauge mark so it stays readable in small app surfaces.
